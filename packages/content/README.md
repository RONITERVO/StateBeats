# @statebeats/content

Original spatial rhythm maps and procedural scores.

Part of StateBeats 0.3.0. ESM with TypeScript declarations and source included.
Use Node 24 LTS; core and SDK also run in modern browsers.

The source release includes complete usage in docs/SDK.md, docs/TOOLS.md and
docs/SCENES_MUSIC_ACCESS.md, plus examples/headless.mjs, examples/scenes.mjs and
examples/extensions.mjs. The reference player uses these same packages for desktop,
standalone WebXR and keyboard/manual text play.

[Project and quick start](https://github.com/RONITERVO/StateBeats) ·
[SDK contract](https://github.com/RONITERVO/StateBeats/blob/main/docs/SDK.md) ·
[Scenes, music and access](https://github.com/RONITERVO/StateBeats/blob/main/docs/SCENES_MUSIC_ACCESS.md)

Release tarballs can be installed together from the source release. The public package
namespace is prepared; publication is a separate maintainer action.

# Original bundled audio

`event-horizon.mp3` is the original 150 BPM, 2:40 Event Horizon composition, dedicated to the
public domain under CC0-1.0. No recordings or samples from other songs are used.

The synthesis source is `scripts/compose-event-horizon.py` in the repository (MIT).
`eventHorizonSoundtrack` from `@statebeats/content` supplies its identity, content hash,
duration and suggested mix. See `docs/EVENT_HORIZON.md` for authoring and reproduction.
